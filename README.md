# AEGIS phone app

The built phone app for AEGIS, served by GitHub Pages at https://aegis-phone-app.github.io/aegis-phone/.

It is a static page only: no data, no keys, no addresses. It talks only to the AEGIS you paired it with, over an end-to-end encrypted channel (Noise XK). Built from the private AEGIS repository by `npm run phone:build`.
